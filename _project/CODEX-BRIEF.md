# CODEX BRIEF — La Rose Wellness Hub static site

Read this file completely before writing anything. Then read the reference
implementation at `build/pages/home.mjs` and copy its conventions exactly.

## What this project is

A bilingual (Arabic RTL / English LTR) static website for **La Rose Wellness Hub**
(`عيادات لاروز التخصصية`), a multi-specialty polyclinic in New Maadi, Cairo.

It is generated by a small Node ESM generator. There is **no framework, no build
tool, no npm dependency**. `node build/build.mjs` reads `content/*.json` and writes
plain `.html` files into `site/`.

```
new site/
  content/*.json      the data (already written — DO NOT EDIT)
  build/
    build.mjs         orchestrator (already written — DO NOT EDIT)
    lib/util.mjs      helpers        (already written — DO NOT EDIT)
    lib/shell.mjs     page shell     (already written — DO NOT EDIT)
    lib/components.mjs shared parts  (already written — DO NOT EDIT)
    pages/home.mjs    REFERENCE — read this, copy its style
    pages/*.mjs       <- YOUR JOB
  site/               generated output + assets
```

## The contract every page module must satisfy

Each file in `build/pages/` exports **one function**:

```js
export function pages({ c, locale }) {
  // c      = all content, already parsed
  // locale = "ar" or "en"  (called once per locale)
  return [ { path: "ar/specialties/index.html", html: "<!doctype html>..." }, ... ];
}
```

- `path` is relative to `site/` and **must start with the locale**: `` `${locale}/...` ``
- `html` is a complete document — produced by calling `page({...})` from `lib/shell.mjs`

### `page()` options

```js
page({
  c, locale,
  depth,        // directories BELOW the locale root. "ar/index.html" = 0,
                // "ar/specialties/x.html" = 1, "ar/a/b/c.html" = 2
  pagePath,     // path WITHIN the locale: "specialties/dermatology.html"
  title,        // <title> — the brand name is appended automatically. null for home.
  description,  // meta description (150–158 chars ideal)
  active,       // nav key to highlight: specialties|doctors|branches|patients|articles|digital|about|contact
  body,         // your page HTML
  schema,       // OPTIONAL extra JSON-LD object, or array of them
})
```

**`depth` is the single most common source of bugs.** Get it wrong and every
link and asset on the page 404s. Count the directories:

| file | depth |
|---|---|
| `ar/index.html` | 0 |
| `ar/contact.html` | 0 |
| `ar/specialties/index.html` | 1 |
| `ar/specialties/dermatology.html` | 1 |
| `ar/articles/some-article.html` | 1 |

## Helpers you MUST use (from `lib/util.mjs`)

| helper | purpose |
|---|---|
| `t(value, locale)` | unwrap `{ar, en}` → string. **Every** piece of content goes through this. |
| `ta(value, locale)` | same, but always returns an array |
| `esc(str)` | HTML-escape. **Every** interpolated string must be escaped. |
| `link(depth, href)` | internal link. Never hand-write `../`. |
| `asset(depth, path)` | asset URL (images, css, js) |
| `icon(name)` | inline SVG. Names: `phone whatsapp pin clock calendar arrow star check info instagram youtube google leaf scale waves stethoscope scalpel activity sparkle heart book monitor user` |
| `sprig(cls)` | the olive-branch ornament |
| `stars(value)` | star rating markup |
| `map(arr, fn)` | `arr.map(fn).join("\n")` |
| `when(cond, html)` | conditional fragment |
| `published(arr)` | filters out `published: false` — **always** apply to specialties, doctors, branches |
| `doctorsIn(doctors, slug)` | doctors for a specialty |
| `bySlug(arr, slug)` | lookup |
| `paras(text)` | plain text → `<p>` blocks |
| `clamp(str, n)` | truncate for meta descriptions |

## Editorial rules — these matter more than the code

1. **Arabic is Egyptian and addressed to the patient**, in the clinic's own warm
   register, usually feminine second person (`انتِ`, `حالتك`, `احجزي`). Look at
   `content/specialties.json` and copy that voice. Never Modern Standard Arabic
   officialese. Never emoji.
2. **Never invent a medical claim, a price, a doctor, a credential, an address or
   a statistic.** Everything factual must already exist in `content/*.json`. If a
   page needs a fact that is not there, write the section so it works without it
   and add a `<!-- TODO(clinic): ... -->` comment.
3. **No prices anywhere on the public site.** This is an explicit client decision.
   Where a price would go, use `t(c.site.ui.priceOnConsult, locale)`.
4. Anything with `sample: true` or `staffed: false` must render a visible
   `badge-sample` marker. The site must never pass placeholder content off as real.
5. Every page that gives health information ends with `medicalNotice({c, locale})`.
6. English is a real translation, not a transliteration — proper British English,
   same meaning, same warmth. Both languages are first-class.

## Accessibility and mobile — non-negotiable

- One `<h1>` per page. Headings descend without skipping.
- Every `<img>` has a meaningful `alt`, or `alt=""` if purely decorative.
- Every form control has a `<label for>`. Never rely on `placeholder` alone.
- Interactive controls are `<a>` or `<button>`, never a `<div>` with a click.
- Icons inside links/buttons that have no text need an `aria-label` on the control.
- Do not set fixed pixel widths or heights on layout containers. The grid
  helpers are already responsive; trust them.
- Tables must be wrapped in `<div style="overflow-x:auto">`.

## Verify before you finish

Run nothing (this sandbox cannot execute node). Instead re-read your own output and confirm:

1. Every file exports `pages({c, locale})` and returns an array of `{path, html}`.
2. Every `path` begins with `` `${locale}/` ``.
3. `depth` matches the directory nesting of every `path` you emit.
4. Every interpolated value is wrapped in `esc()` unless it is already HTML.
5. Every `{ar, en}` value is unwrapped with `t(..., locale)`.
6. You used `published()` on specialties, doctors and branches.
7. No `<style>`, no `<script>`, no invented class names.
8. Balanced backticks and braces — the file must be valid JavaScript.
