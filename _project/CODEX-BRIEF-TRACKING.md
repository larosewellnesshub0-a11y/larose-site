## 2. Event tracking layer — new file `site/assets/js/track.js`
Loaded by every page (add it to the script list in `shell.mjs` and the RecipeGuide pages, `defer`). Dependency-free, must be a silent no-op when no tag ids are configured. Expose `window.LRTrack.event(name, params)` which:
- pushes `{event: name, ...params}` to `window.dataLayer`,
- calls `gtag('event', name, params)` if gtag exists,
- calls `fbq('trackCustom', name, params)` if fbq exists, and additionally `fbq('track','Lead')` for `booking_submit` and `fbq('track','Contact')` for `whatsapp_click` / `call_click`,
- calls `ttq.track(...)` if ttq exists (`SubmitForm` for booking_submit, `Contact` for whatsapp/call),
- calls `clarity('event', name)` if clarity exists.
Auto-bind (event delegation on `document`, works for elements added later):
- click on any link to `api.whatsapp.com`, `wa.me`, `whatsapp.com` → `whatsapp_click` `{location: <nearest section id or data-track attr or 'page'>, page: location.pathname, lang}`
- click on `tel:` links → `call_click`
- submit of a form with `data-form-source="booking"` (check what the booking form actually uses in `build/pages/patients.mjs` / `forms.js`; use that) → `booking_submit` `{specialty, branch}`; any other form → `form_submit` `{source}`
- click on links to `/RecipeGuide/` or `/RecipeGuide/free/` or with `data-track="recipe-guide"` → `recipe_guide_cta` `{target: 'landing'|'free'}`
- click on instagram/youtube/linktr.ee/facebook/tiktok links → `social_click` `{network}`
- click on the language switch (`hreflang` link in the header — see `shell.mjs`) → `language_switch` `{to}`
- scroll depth 25/50/75/100 once per page → `scroll_depth` `{percent}`
- health tool result rendered (hook the existing `tools.js` result panel: dispatch a `CustomEvent('lr:tool-result', {detail:{tool}})` from `tools.js` where a result is shown) → `tool_used` `{tool}`
- outbound `maps.app.goo.gl` / google maps links → `directions_click` `{branch}`
