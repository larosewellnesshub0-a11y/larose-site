# YOUR JOB: make the whole site SEO and GEO (generative-engine) ready.

Nothing here should change how any page LOOKS. This is head, structured data and
crawler files only. Do not touch CSS, and do not touch page body markup except
where a task below explicitly says to.

The canonical domain is in `content/site.json` at `brand.domain`. Always build
absolute URLs from it as `https://<domain>/<locale>/<path>`. Never hardcode it.

## A1. hreflang + canonical (build/lib/shell.mjs)

Every page currently lacks language alternates. In `page()`'s `<head>` emit:

- `<link rel="canonical" href="<absolute url of this page>">`
- `<link rel="alternate" hreflang="ar" href="<absolute /ar/ url>">`
- `<link rel="alternate" hreflang="en" href="<absolute /en/ url>">`
- `<link rel="alternate" hreflang="x-default" href="<absolute /ar/ url>">`

`page()` already receives enough to know the page's own path — find how the
locale counterpart path is derived (the validator already checks counterparts
exist, so the rule is just swapping the leading `ar/` or `en/` segment).

## A2. Social cards (build/lib/shell.mjs)

Add Open Graph and Twitter meta: `og:type`, `og:site_name`, `og:locale`
(`ar_EG` / `en_US`), `og:locale:alternate`, `og:title`, `og:description`,
`og:url`, `og:image`, `twitter:card` = `summary_large_image`, `twitter:title`,
`twitter:description`, `twitter:image`.

`og:image` must be an ABSOLUTE url. Accept an optional `image` argument on
`page()`; when a caller does not pass one, fall back to
`assets/img/clinic/hero-clinic-1200.webp`. Add `og:image:width`/`height`.
